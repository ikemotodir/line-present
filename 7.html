ClaudeCodeセットアップガイド

Claude をパソコンに入れ、Claude Code に最初のファイルを作ってもらう所まで、順番に。黒い画面（ターミナル）は使いません。

先に知っておく事

  • 無料プランでは使えません。 Pro 以上の有料プランが要ります
  • 料金ページの Pro は「月払いの場合は $20」（2026年11月確認）。日本で払う金額と税は、申し込みの画面で確かめてください
  • Pro には5時間ごと・週ごとの使用量の上限があります。上限によく当たる人は Max（Pro の5倍の使用量）も
  • 使えるのは18歳以上です（規約）
  • 解約するまで自動で更新・請求され、支払いは原則として返金されません（規約）
  • やめる時は、設定 ＞ お支払い（画面によっては「請求」）の「キャンセル」。更新日の少なくとも24時間前に
  • パソコンは Windows 10（1809 以上）か macOS 13 以上、メモリ 4GB 以上

手順（上から順に）

  1. 料金ページを開き、Pro の「Claude を試す」を押す
  2. アカウントを作り（持っている人はログイン）、画面の案内どおりに Pro の申し込みを終える
  3. ダウンロードページで「Windows」の「ダウンロード」を押す（Mac は「macOS」）。ARM のパソコンだけは「Windows（arm 64）」。ARM かどうかは、Windows の設定 → システム → バージョン情報 の「システムの種類」で分かります
  4. ダウンロードしたファイルを開き、インストールを終える
  5. スタートメニュー（Mac はアプリケーション）から Claude を開き、ログイン
  6. 画面を日本語に：左下のプロフィールのアイコン →「言語」（英語の画面では「Language」）→ 日本語
  7. サイドバー上部の「Code」を押す（アイコンだけなら、マウスを合わせると名前が出る）
  8. 作業用のフォルダを作る。Windows は Windows キー + E → 作る場所（例：ドキュメント）で「新規」→ フォルダー。Mac は Finder で作る場所を開き「ファイル」＞「新規フォルダ」。名前は英数字（例：claude-work）
  9. 入力欄の下の行の一番左（環境）で「ローカル」の一番上 → 隣のフォルダの所 →「フォルダを開く…」→ 8 のフォルダ（英語の画面では Local・Open folder…）
  10. 同じ行でモードを選べます。1つずつ確かめたい人は「手動」（英語の画面では Manual）
  11. 下の最初の一言をコピーして入力欄に貼り、Enter
  12. 許可を聞かれたら、内容を読んでから許可。聞かれずに進めたい人は Lv.3 へ

画面は版で違うことがあります。黒い画面で入れたい人は、公式のターミナルガイドへ。

最初の一言（コピーして貼る）

これから Claude Code を初めて使います。パソコンが苦手な人にも分かるように進めてください。途中で質問はせず、最後まで自分で進めてください。

1. このパソコンが Windows か Mac かを確かめてください。確かめるだけにして、何もインストールせず、設定も変えないでください。今開いているフォルダに書けるかどうかは、2 のファイルを作れたかで確かめてください。
2. 今開いているフォルダに、はじめてのメモ.md を1つだけ作ってください。中身は次の4つにしてください。
   ・今日の日付
   ・1で確かめた結果
   ・Claude Code に頼めることの例を3つ（初心者向けに1行ずつ）書いてください
   ・次にやるとよいことを3つ書いてください
3. このフォルダの外のファイルは触らないでください。
4. 作ったら、ファイルが本当にあるか読み直して確かめてから報告してください。
5. 報告は、専門用語を使わずに、次の順に1行ずつ書いてください。
   ・このパソコンで使える状態か
   ・作ったファイルの名前と場所
   ・次にやること

つまずいたら

  • 「Code」を押すとアップグレードの案内が出る：有料プランの申し込みが先です
  • サインインを促す案内が出る：サインインを終えて、アプリを再起動する
  • 403 などの認証エラーが出る：アプリのメニューからサインアウトし、もう一度サインイン
  • 環境を選ぶ所が入力欄の上にある：古い画面。「ヘルプ」→「アップデートを確認…」で新しくする（Mac は「Claude」の中。英語の画面では Help（Mac は Claude）→ Check for Updates…）

次にやること

  • Lv.3：許可を聞かずに最後まで動く設定 Lv.3 を開く
  • Lv.5：嘘を抑えるルールを覚えさせる Lv.5 を開く
