【圧倒的に楽】
AIの情報収集能力UPガイド

なぜ作ったか

ボクの記憶だと、最初にAIへ、動画の音声を文字にできるか聞いたら「その機能は付いてません。できません」と言われました。少なくとも初期のころは、URLを1つ渡しても、その先のページまでは読んでくれませんでした。
それが、なんか気づいたらできるようになってたんですね。
その「気づいたら」までの遠回りを、丸投げで飛ばすための特典です。

できるようになる事

  • パソコンの中のファイルを、自分で探して読む
  • URLの中身と、その先のリンクまで読む
  • ログインが要る自分のページを読む
  • 長いPDF・画像の文字を読む
  • パソコンにある動画を文字にする（ARM の Windows では使えないことも）

先にやっておく事

  • Lv.2 を終えて、Claude Code が使える
  • Claude の有料プラン（Pro 以上）
  • ブラウザは Google Chrome Chrome を入れる

① 丸投げする

丸投げファイルをダウンロード
情報収集能力UP_丸投げ.md
読み込み中…

Claude Code でフォルダを選び（Lv.2 の物でOK）、中身を貼って送るだけ。許可を何度か聞かれたら、内容が丸投げ文のとおりなら許可。
入るのは、聞かずに読む・探す許可（鍵のファイル .env などは読まない。ただしプログラムが開く時は止まりません）、文字にする無料の部品、探し方の決まり。

  • Lv.3 の「権限をバイパス」でなくても効きます
  • 作業フォルダの外を読んでよいか聞かれたら、今後も許可する方を選ぶ（今後はブロックする方だと、どのモードでも外を読めなくなる）
  • Mac がフォルダを読む許可を聞いてきたら許可
  • 丸ごと覚えさせるなら Lv.6、動画を文字にするアプリは Lv.7

② ログインが要るページ用の拡張を入れる

Chrome の拡張（Claude in Chrome）です。クリック・入力・送信もでき、結果の責任は使う人に。許可は、頼んだ事だけか確かめてから。

Chrome ウェブストアで開く

  1. パソコンの Chrome でこのページを開き、上のボタン →「Chrome に追加」→「拡張機能を追加」
  2. 聞かれたら、Claude Code と同じアカウントでサインインし、権限を許可
  3. パズルのピースの形のボタン →「Claude」の横のピン
  4. アプリの左下のイニシャル →「設定」→「カスタマイズ」→「コネクタ」→ Claude in Chrome の「設定」→ オンにする
  5. 使う時は Chrome を開いておく。読めない時は Chrome を開き直し、その会話のコネクタで Claude in Chrome がオンか見る（公式：会話ごとにオン）

画面は版で違うことがあります。公式のおすすめは、銀行・医療・役所などのアカウントが無い別のプロファイル（右上のプロファイル →「Chrome プロファイルを追加」）で1〜5をやる事。

やってはいけない事

  • YouTube の動画をURLから落とさない（規約で禁止）。YouTube はAIに読ませず、自分で説明欄の「文字起こしを表示」を見る（字幕付き）
  • ログインを回避しない（読むのは自分が見られるページだけ）
  • パスワードや顧客情報の入った物は読ませない。他人の個人情報も集めさせない
  • 読ませる物の権利とサイトの規約は自分で確かめる
  • ① の設定で、URLを読む前の確認が無くなります。知らないサイトは、AIへの悪い指示が隠れていることがあるので読ませない
  • 読んだ中身は、会話の記録としてパソコンと Anthropic 側に残ります（Anthropic 側は学習の設定で30日か5年）
