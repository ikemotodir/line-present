Claudeを作るAnthropic（アンソロピック）社の無料講座（英語）やヘルプから、ボクの言葉で20個。
同社が作った・認めた資料ではなく、関係もありません。

Claudeってどんな相手？

  1. もっともらしく間違える：自信ありげでも事実と違うことがある。
  2. 知識に区切りがある：最近の話は知らないことも。「ウェブで調べて」と頼む。
  3. 長いチャットほど早く上限に届く：上限が近いなら新しいチャットへ。
  4. 別のチャットでも要点を覚える：無料でも「メモリ」が最初からオン。
  5. できないのに「やった」と言う：メールとつないでいないのに「送った」など。

うまく頼むコツ

  1. こちらの事情は知らない：誰向け・何に使う・なぜ、を書くほど的確に。
  2. 形は数字で言う：「3行で」「箇条書き5つで」と伝える。
  3. 見本を見せる：説明より見本のほうが形がそろいやすい。
  4. 長い資料は先に貼る：指示や質問は資料のあとに。
  5. 大きな頼みは小分けに：献立→買い物リストの順に。

答えと情報の扱い方

  1. 一発で決めなくていい：結果を見て具体的に直しを頼む。
  2. 頼み方ごと直してもらう：頼む文を貼って「頼み方を良くして」と。
  3. 数字とリンクは確かめる：出典を開いて自分の目で。
  4. AIの答えも自分の責任：職場では使ったと伝える。
  5. 秘密は入れる前に考える：カード番号・パスワード・社外秘など。

便利な機能

  1. 好みを先に伝える：設定の指示の欄に書くと全チャットに効く。
  2. プロジェクト：資料と指示を置けば毎回説明不要（無料は5個まで）。
  3. アーティファクト：作った文書や道具を別枠に出し、手直しも共有も（設定でファイル作成をオン）。
  4. コネクタ：つなぐとGmailやGoogleカレンダーも探せる。
  5. シークレットチャット：履歴・メモリに残らず、AIの学習に使われない（Anthropicには30日残る）。
