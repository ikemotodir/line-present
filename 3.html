特典 3

【まずこれ作れ①】AI学習を効率化する「動画テキスト化ツール」丸投げ開発ノート

ボクが AI（Claude）に作ってもらった、無料の文字起こしアプリ「PATTI SCRIBE」の作り方の記録です。

ボクはプログラムを1行も書いていません。書いたのは「こうしたい」という要望と、「ここが変」という報告だけです。

このノートで分かること

  • 動画を文字にすると、なぜ AI での学びが速くなるのか
  • ボクが AI に最初にどう頼んだか
  • 途中でつまずいたところと、AI とどう直したか
  • 完成品（無料）の使い方
  • 自分で作るときに、そのままコピーして使える頼み方

1. なぜ作ったのか

きっかけは、自分の困りごと

ボクは映像の仕事をしています。テレビ番組や YouTube の編集では、インタビューや対談を毎回「文字に起こす」作業があって、ここに大きな時間を取られていました。

ネットの文字起こしサービスも便利です。でも、

  • 月額の料金がかかる
  • 放送前の素材を、よその会社のサーバーに送ることになる

この2つが気になっていました。だから「自分のパソコンの中だけで文字にできる道具」がほしかったんです。

いまは「AIで学ぶ」ための道具にもなる

動画のままだと、あとから中身を探したり、AI に渡したりしにくいですよね。文字にしておくと、

  • チャットの AI にそのまま貼って「要点をまとめて」「明日やることを3つにして」と頼める
  • 何度も見返さなくても、言葉で探せる
  • 自分用の「教科書」として残せる

講座の動画、オンラインで話したときの録画、自分が話した動画。文字にするだけで、AI と一緒に復習できるようになります。

※文字にするのは、自分で撮った・録ったもの、または使ってよいと許可されているものだけにしてください。

2. 最初にどう頼んだか

ボクが最初に AI に伝えたのは、これだけです。

「動画データや音声データから声を抽出してテキストにしたい。YouTubeのURLからも文字起こししたい。この2つを叶えるアプリを作ってほしい」

ポイントは3つです。

  • 「何をしたいか」だけを、ふつうの日本語で伝えた
  • 「このプログラムの言葉で」「この部品を使って」といった作り方の指定はしていない。作り方は AI が選ぶ
  • 専門用語は使っていない

AI は、無料で公開されている部品を組み合わせて作りました。中心は、OpenAI が無料で公開している音声認識の AI「Whisper（ウィスパー）」です。部品がすべて無料なので、完成品も無料で配れました。

ボクのときの役割分担

だれやったことたとえると
ボク要望を出す・実際に使う・変なところを報告する・最後に決める家を建ててもらう施主
Claude（チャット）設計する・プログラムを書く設計士
Claude Codeボクのパソコンの中で、実際にファイルを組み立てる現場の大工さん

Claude Code は、パソコンの中のファイルを読んだり作ったりしながら開発を進めてくれる AI です。公式の説明でも、やりたいことをふつうの言葉で伝えると、進め方を考え、プログラムを書き、動くかどうかの確認までする、とされています。

3. 開発の流れ

ボクの場合は、こんな順番で進みました。

① まず最初の形ができる
動画や音声のファイルを入れると文字になる。YouTube の URL からも文字にできる（自分用）。

② 「使う → 変なところを伝える → 直してもらう」をくり返す
ここがいちばん大事な工程でした。自分の仕事で毎日使いながら、たとえばこんな順に良くなっていきました。

  • 冒頭の声が文字にならない → 直す（4章でくわしく）
  • 2本目のファイルを入れたのに、1本目の結果が出たまま → 直す
  • マイクが何本もある録音（16本分でも）に対応
  • 左右2本のマイクで録った同じ人の声を、2人ではなく1人として扱う
  • 編集ソフト用のテロップ（字幕）を自動で作る。1行の文字数で改行する。中央にそろえる

③ 「自分用」と「人に配る用」を分ける
人に配る版からは、YouTube の URL から文字にする機能を外しました。YouTube の利用規約では、YouTube が明示的に許可した場合などを除いて、ダウンロードが禁止されています。自分の動画で使うのと、たくさんの人に配るのとでは責任の重さが違う、と判断しました。

④ 「解凍してダブルクリックするだけ」で動く形にする
最初は、別のソフトを先にインストールしないと動かない作りでした。これでは難しいので、必要な部品を全部アプリの中に入れた「そのまま動く版」にしました。
これは Claude Code の仕事です。組み立て方の指示書はチャットの Claude が書いてくれたので、ボクが出した指示は実質1行でした（ファイル名などを省いて書くと、こうです）。

（指示書の場所）を読んで、その通りに組み立てて。終わったら結果を書いて

⑤ 無料で公開する
GitHub（プログラムを置いて公開できるサービス）に置き、配布ページも作りました。ホームページの住所（ドメイン）の代金も、サーバー代もかかっていません。

⑥ 公開した日に、自分が「最初の利用者」になる
最初から最後まで通しで使ってみて、5つの不具合を見つけて直しました（4章）。

⑦ 公開後も育てる
新しい版が出たら、アプリを起動したときにお知らせが出るようにしました。勝手にファイルを書き換えるのではなく、お知らせを見て自分で入れ替える方式です。
自分用の版には、公開のあとも、デスクトップにアイコンを置く・黒い画面を出さない・ブラウザを閉じたらアプリも終わる、といった使い心地の改善を入れていきました（4章のつまずき⑥）。

4. つまずいたところと、AIとどう直したか

ボクがやっていた「報告の型」

AI に早く直してもらうコツは、報告の仕方でした。

  1. どの画面で起きたか
  2. 何が起きたか
  3. 画面の写真（エラーの文字が写っていると一気に進む）
  4. どうすると起きるか（例:「2つ目のファイルに入れ替えたら」）

「なんか変」ではなく、「00:02〜00:30 の声が文字になっていない」のように、時間と症状を伝える。これで AI は当てずっぽうではなく、原因から直してくれました。

つまずき① 冒頭の声が消える

  • 起きたこと: 「00:02-00:30の音声が一切テキスト化されてない」
  • 原因: 困っていた録音ファイルをそのまま AI に渡したら、AI がファイルを調べて、4本のマイクの音が別々に入った録音で、最初の28秒は一部のマイクにしか声が入っていないことを数字で突き止めました。ほかにも、動画に入っている音声の一部しか読んでいなかったこと、0秒ちょうどから始まる声を AI が取りこぼしやすいことが重なっていました
  • 直し方: 音の大きさをそろえる／入っている音声を全部まとめて読む／冒頭に1秒の「無音のすき間」を足してから文字にし、時刻はあとで戻す。一度では直りきらず、「やっぱり冒頭がおかしい」と報告しながら3回に分けて直しました
  • 学び: 推測で直すより、困っている実物を渡すほうがずっと早い

つまずき② 小さい声を「無音」と判定して飛ばす

  • 起きたこと: 声のない所を飛ばす機能（長い無音が多い素材で、処理を速くするため）が、小さな声まで「無音」と判断して、まるごと飛ばしてしまった
  • 直し方: 判定をゆるくして、1.5秒以上つづく無音だけを飛ばす。声の前後には少し余白を残す

つまずき③ 速くするための部品が「見つからない」と止まる

  • 起きたこと: パソコンの画像処理用の部品（GPU）の力を借りて速く動かそうとすると、エラーで止まることがあった
  • 原因: GPU を動かすための追加ファイルはパソコンに入っていたのに、Windows がその置き場所を見つけられていなかった
  • 直し方: 置き場所をアプリから Windows に教えるようにした。さらに、本番の前に0.5秒の無音で「試し運転」をして、ダメなら自動でふつうの処理（CPU）に切り替える。だから GPU がうまく動かなくても、止まらずに文字起こしを続けます

つまずき④ 初めて起動すると、何も起きない

  • 起きたこと: ダブルクリックしても、何も起きないように見えた
  • 原因: 画面を作る部品が、初回だけ裏の黒い画面で、メールアドレスの入力を（英語で）求めて待っていた。黒い画面は小さくしてあったので、聞かれていることに気づけなかった
  • 直し方: 起動する前に、その質問への答え（空欄）を自動で用意しておくようにした

つまずき⑤ 公開した日に見つかった5つ

自分が最初の利用者として通しで使って、見つけたものです。

  1. ダウンロードしたあと、何をすればいいか分からない → 説明書への案内を追加
  2. 説明書が開けない → メモ帳で開ける形に変更
  3. デスクトップにアイコンを作るファイルが、文字化けしてエラー → 正しい文字の形式で作り直し
  4. 文字起こしでエラー → ③の「試し運転」で確実に切り替え
  5. 黒い画面が怖い、残る → 起動したら自動で小さくする

つまずき⑥ 黒い画面を消したら、終わらせ方がなくなった

  • 起きたこと: 自分用の版で黒い画面を完全に消したら、それまでの「黒い画面を閉じる＝アプリが終わる」が使えなくなった
  • 直し方: ブラウザとアプリをつないでおき、「つながりがゼロの状態が8秒続いたら、アプリが自分で終わる」ようにした。8秒待つのは、ページを読み込み直した一瞬の切断で終わってしまわないため

5. 完成品の使い方と入手先

PATTI SCRIBE は無料で配っています（Windows 用）。

  • 配布ページ: https://ikemotodir.github.io/patti-scribe/
  • 登録不要・課金なし
  • 文字にする作業はパソコンの中だけで行います。音声や動画のデータは外に送りません

はじめかた（配布ページより）

  1. 配布ページの「⬇ 無料ダウンロード（Windows）」から ZIP（いくつものファイルを1つにまとめたもの）を受け取る
  2. ZIP を解凍する（日本語を含まない場所がおすすめ。例: C:\tools）
  3. フォルダの中の「PattiScribe.bat」をダブルクリック
  4. ブラウザが自動で開いたら準備完了。動画や音声をドラッグするだけ
  • 別のソフトのインストールは不要です（中に入っています）
  • 最初の1回だけ、AI の本体（約1.6GB）のダウンロードがあります
  • くわしくはフォルダ内の「README.txt」を読んでください。起動したときに Windows の警告画面が出た場合の進め方も書いてあります
  • デスクトップのアイコンは「create_shortcut.bat」をダブルクリックで作れます
  • 終わるときは、ブラウザのタブを閉じたあと、タスクバーに小さくなっている黒い画面（アプリの本体）も閉じます

できること

  • mp4 / mov / wav / mp3 など主な形式に対応。複数のファイルをまとめて処理
  • 保存できる形は「テキスト」「タイムスタンプ付き」「SRT字幕（テロップ用）」「EDIUSテロップ」（EDIUS という編集ソフト用のテロップ一式）の4つ
  • 1人ずつ別のマイクで録った対談なら、話している人ごとに「話者1：」「話者2：」と分けられる
  • NVIDIA 製の GPU があるパソコンなら、同梱の「setup_gpu.bat」で速くできる
  • 処理の速さは、パソコンの性能しだいです

文字にしたあと、AIで学ぶ

「テキスト(.txt)をダウンロード」で保存して、中身をチャットの AI に貼り、こう頼みます。

※文字にした結果は、アプリの画面の中にしかありません。ブラウザのタブを閉じる前に保存してください。保存がうまくいかないときは、結果の「テキスト」のタブに出ている文字を全部選んでコピーし、メモ帳などに貼っておけば残せます。

これは、わたしが受けた講座（または打ち合わせ）の文字起こしです。
1. 大事なポイントを5つ、やさしい言葉でまとめてください
2. わたしが明日からやることを3つ、順番に並べてください
3. 聞き取りミスらしい言葉があれば、正しそうな言葉を横に書いてください

（ここに文字起こしを貼る）

新しい版が出たら

アプリを起動したときにお知らせが出ます。お知らせの「ダウンロードページへ」から新しい ZIP を受け取り、今まで使っていたフォルダにそのまま上書きで解凍すれば完了です。デスクトップのアイコンもそのまま使えます。

（2026年9月26日時点で配っているのは v1.2 です）

6. 自分で作るなら: Claude Code に丸投げする指示文

用意するもの

  • Windows のパソコン
  • Claude の有料プラン（Claude のデスクトップアプリで Claude Code を使うには、有料プランが必要と公式に書かれています）
  • Claude のデスクトップアプリを開いてサインインし、「Code」タブを選ぶ
  • 作業用のフォルダを1つ（名前に日本語や記号を入れない）

頼むときのコツ（ボクの開発記録から）

  • ファイルは「渡す」より「置く」。Claude Code はパソコンの中のファイルを直接読めるので、置いた場所を伝えればいい
  • 場所は省略しないで伝える。どこで起動していても迷わないように
  • 文字化けしやすいファイルは「編集しないで、そのままコピーして」とはっきり書く。気を利かせた編集で壊れたことがあった
  • 置き場所の名前に日本語を入れない。PATTI SCRIBE の説明書でも、日本語を含まない場所をすすめています（文字化けや、起動しない原因になることがあるため）
  • 1回で完璧を目指さない。使ってみて、報告して、直してもらう。これで十分進みます

コピペ用: 最初の指示文

あなたは、プログラミングを知らないわたしの代わりに、
パソコンの中だけで動く「動画・音声の文字起こしアプリ」を作る開発担当です。

【作りたいもの】
・動画や音声のファイル（mp4、mov、mp3、wav、m4a など）を入れると、
  話している言葉を日本語の文字にしてくれるアプリ
・結果は「文字だけ」「時刻つき」「字幕ファイル（SRT）」の3つで保存できる
・複数のファイルをまとめて入れられる
・入れた動画や音声は、インターネットに送らない（パソコンの中だけで処理する）
・Windows で使う。ボタンとドラッグで操作できる画面にする

【使い心地で守ってほしいこと】
・デスクトップにアイコンを作り、ダブルクリックだけで起動する
・黒い画面（コマンドプロンプト）を出さない
・画面を閉じたら、アプリも自動で終わる
・文字にした結果は、保存ボタンを押さなくても自動でファイルに残す（画面を閉じても消えないように）
・初めて起動したときに、途中で止まって何も起きない、ということがないようにする
・置く場所の名前に日本語が入っていても壊れないか、確かめる

【文字起こしの質で守ってほしいこと】
・0秒からいきなり話し始める音声でも、冒頭の声を取りこぼさない
・小さな声を「無音」と判定して飛ばさない
・マイクが何本もある録音や、音声が何本も入っている動画でも、全部の声を拾う
・速くするために GPU を使う場合は、使えなかったら自動でふつうの処理に切り替えて、止まらないようにする

【進め方】
・使う部品や方法は、無料で使えるものの中からあなたが選んでください。
  選んだら、何を使うかを専門用語なしで1行ずつ説明してください
・作ったら、あなた自身で短い音声を用意して実際に文字起こしを試し、
  うまくいったことを確かめてからわたしに渡してください
・わたしが試すときの手順を、クリックする順に書いてください
・わたしが「うまくいかない」と伝えたら、原因を調べて直してください。
  必要なら、わたしから実際のファイルを受け取って調べてください

コピペ用: うまくいかないときの報告文

【うまくいかないこと】
・どの画面で：
・何をしたら：
・どうなった：（エラーの文字があれば、そのまま貼る。画面の写真も付ける）
・何回やっても同じか：
・試したファイル：（可能なら、そのファイルを置いた場所を書く）

さいごに

ボクがやったのは、「作ってほしいもの」を伝えることと、実際に使って「変なところ」を正確に伝えることだけでした。
まずは完成品の PATTI SCRIBE を使ってみて、「自分ならここをこうしたい」が見えたら、上の指示文に書き足して Claude Code に頼んでみてください。
