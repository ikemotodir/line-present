特典 3

【まずこれ作れ①】AI学習を効率化する「動画テキスト化ツール」丸投げ開発ノート

なぜ作ったか

テレビや講座の動画を、毎回自分で文字にしていました。文字にすればAIに渡して「要点は？」「明日やることは？」と聞けます。でも外のサービスは月額がかかり、素材を外に送るのも不安。だから自分のパソコンの中だけで文字にする道具を、AIに丸投げで作ってもらいました（PATTI SCRIBE）。

コピペするだけ

Claude Code（デスクトップアプリの「Code」）で新しいフォルダを開き、下を貼ります。Windows・Macどちらでも動くように頼んであります。

パソコンの中だけで動く「動画・音声の文字起こしアプリ」を作ってください。
私はプログラムが分かりません。作るところから試すところまで任せます。

【作ってほしいもの】
・動画・音声（mp4 / mov / mp3 / wav / m4a）を入れると、日本語の文字にする
・結果は「文字だけ」「時刻つき」「字幕（SRT）」の3つで、自動でファイルに保存する
・入れたデータはネットに送らない（無料で使える音声認識AIを使う）
・ブラウザで開く画面で、ドラッグして使える

【WindowsでもMacでも】
・このパソコンがWindowsかMacかを自分で調べ、それに合わせて準備する（必要なソフトの導入も）
・デスクトップに、ダブルクリックで起動するアイコンを作る（Windowsは .bat、Macは .command）
・黒い画面を出しっぱなしにしない。画面を閉じたらアプリも終わる

【最初から対策してほしいこと】
・0秒から話し始める音声でも、冒頭を取りこぼさない
・小さい声を「無音」と判断して飛ばさない
・初めての起動で、途中の質問に止められない
・GPUが使えないパソコンでも、自動でふつうの処理に切り替えて止まらない

【進め方】
・作ったら、自分で短い音声を用意して試し、うまくいってから渡す
・私がやる操作を、クリックする順に3行以内で教える

細かい解説

  • 対策の4つは、ボクが実際につまずいた所です。最初から入れておくと、やり直しが減ります
  • うまくいかないときは「どの画面で・何をしたら・どうなった」を、画面の写真と一緒に伝えると早く直ります
  • 作るのが大変なら、完成品（Windows・無料）もあります → https://ikemotodir.github.io/patti-scribe/
