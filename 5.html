【誰でもOK】オンライン個別相談の無料権

「AIって、結局なにから始めたらいいの？」

その答えは、人によってちがいます。
だから、まずはあなたのお話を聞くところから始めます。

60〜90分のオンライン個別相談を、無料で受けられる特典です。

先にお伝えしておきたいこと

  • 相談の最後のほうで、ボクのAI講座（有料）のご案内をすることがあります。受けるかどうかは自由です。聞くだけでも大丈夫です。
  • 録画をするときは、始める前に必ずお聞きします。断っていただいて大丈夫です。
  • 相談は無料です。あとからお金をいただくことはありません。

こんな方へ

  • AIが気になっているけど、何から始めればいいか分からない
  • ChatGPTを使ってみたけど、調べものくらいで止まっている
  • 子育てと仕事で手いっぱいで、「自分がもう1人ほしい」と思うことがある
  • 特典1〜4を読んで、「自分の場合はどうなるんだろう」と聞いてみたい

相談でやること（4つ）

① 今のお悩みを聞いて、いっしょに整理します
「今のこと」→「これまでのこと」→「やりたいこと」→「悩みや不安」の順に、ボクが聞き役になってお話を伺います。
話したくないことは、話さなくて大丈夫です。

② AIのちがいを、表で見ながらお話しします

  • ChatGPT・Gemini・Claude など、よく名前を聞くAIのちがい
  • 話しかけて答えてもらう「チャット用のAI」と、パソコンの中でファイルを作ったり直したりしながら作業を進めてくれる「開発用のAI（Claude Code など）」のちがい

便利なぶん、気をつけることもあります。大事なファイルを勝手に消させない頼み方や、AIの学習に使わせない設定も、セットでお伝えします。

③ ボクが実際に使っている画面をお見せします
ボクの場合は、たとえばこんな画面です。

  • ボクが書いてきた記事をAIに読み込ませて、手伝ってもらっている様子
  • AIの「メモリ」（AIがあなたのことを覚えておく場所）に入れている、ボクの「絶対ルール」
  • ボクが寝ているあいだに、AIに開発を進めてもらっている様子
  • 言葉で頼みながら、会社のホームページ（パソコン版・スマホ版）を作ってもらった流れ

④ お話の内容を、あなた専用の「ナレッジファイル」にしてお渡しします（ご希望の方だけ）
ナレッジファイルは、あなたの「今」「これまで」「やりたいこと」を、1つの文章にまとめたものです。
ChatGPT や Claude などのAIに読ませると、あなたのことを知ってもらったうえで答えてもらうための材料になります。

  • 相談のあと、LINEでお届けします
  • 講座を受けるかどうかとは関係なく、お渡しします
  • いらない場合は、遠慮なく言ってください。その場合は作りません

申し込み方

STEP1　公式LINEのトークに「相談」と送ってください

相談

STEP2　ボクからお返事します
ご都合のよい日にちと時間を、LINEで相談して決めましょう。
ボク1人で対応しているので、ご希望の日時に沿えないこともあります。ごめんなさい。

STEP3　当日、ビデオ通話のURLをLINEでお送りします

STEP4　60〜90分お話しします
終わりの時間は、始めるときにお伝えします。夜遅くならないように、開始は遅くても20時まで、21時には終わる時間で組んでいます（20時に始める場合は60分）。

STEP5　（ご希望の方）ナレッジファイルをLINEでお届けします

用意していただくもの

  • パソコンかタブレット（ボクの画面をお見せするので、大きい画面のほうが見やすいです。スマホでも参加できます）
  • 落ち着いて話せる場所
  • 聞いてみたいことのメモ（なくても大丈夫です）

先にお伝えしておくこと（くわしく）

1. 有料のAI講座のご案内について
相談の最後のほうで、ボクのAI講座（有料）のご案内をすることがあります。受けるかどうかは自由です。

  • 相談を始めるときにも、このことをあらためてお伝えします
  • 聞くだけでも大丈夫です。その場で決めていただくことはありません。持ち帰って、ご家族とも相談してみてください
  • 料金や、受講料のほかにかかるお金などの条件は、ご案内するときに資料でお見せします
  • 「いりません」と言っていただいたら、その場でも、あとからも、ボクから講座をおすすめすることはしません

2. 録画について

  • ボクの振り返りのために、録画をお願いすることがあります。録画するときは、始める前に必ずお聞きします
  • 断っていただいても、相談の中身は変わりません
  • 録画は、ボクの振り返りとナレッジファイル作りにだけ使います。人に見せたり、公開したりはしません（まとめ作りでAIを使うときのことは、下の3に書いています）
  • 消す日を決めて、その日をお伝えします。「すぐ消してほしい」と言っていただければ、すぐに消します

3. お話の内容と、AIについて

  • ナレッジファイルを作るときは、AI（Claude。アメリカの Anthropic という会社のサービス）を使います
  • 会話をAIの学習に使わせない設定にしたうえで、お名前・ご家族やお客さまのお名前・お勤め先などは消してから入れます（この設定でも、会話は Anthropic のサーバーに30日間保存されます）
  • 体調やご病気のお話は、まとめに入れません
  • AIを使ってほしくない、まとめはいらない、という場合は、遠慮なく言ってください
  • LINEやお話で教えていただいたことは、日程の調整、この相談とまとめ作り、ボクの振り返り（録画した場合）、相談の中でご希望があったときの講座の資料のお届けのためにだけ使います

4. 無料です

  • 相談もナレッジファイルも無料です。あとからお金をいただくことはありません
  • 講座を受けることは、相談を受ける条件ではありません

ボクからひとこと

ボクもずっと、やりたい事と時間のあいだで葛藤してきました。
AIに出会ってから試してきたことを、画面を見せながら、そのままお話しします。
60〜90分、あなたのお話を聞かせてください。
