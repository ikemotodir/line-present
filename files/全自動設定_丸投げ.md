# 全自動で動く設定 ― Claude Code への丸投げ指示書

あなた（Claude Code）への依頼です。私のパソコンの Claude Code を、**いちいち許可を聞かずに最後まで自動で進める**設定にしてください。そのかわり、事故が起きにくいように守りの設定も一緒に入れてください。私はプログラムが分かりません。途中で質問せず、最後まで進めてください。

## やってほしいこと
1. ユーザー用の設定ファイル `~/.claude/settings.json` を開く（Windows なら `%USERPROFILE%\.claude\settings.json`）。無ければ作る（`.claude` フォルダ自体が無ければ、それも作る）。書き込むときに許可の画面が出たら、私に「はい」を押すよう1行で伝える（出なければ何もしなくてよい）。
2. 変更前に、元のファイルがあれば日付つきでコピーして残す（名前は `settings.json.bak-` に実行した日の日付。例: `settings.json.bak-20261014`）。元から無ければコピーは要らない。
3. すでにある設定は消さずに、次を足す（JSON の形を壊さない。すでに `ask` や `deny` の一覧があるときは、その一覧に足し、同じ物を二重に入れない）。
   - `permissions.defaultMode` を `"bypassPermissions"` にする（新しいフォルダでは、許可を聞かないモードで始まる。前に別のモードを選んだフォルダは、そのモードのまま）。このモードは、下の「画面でやること」1のスイッチを私がオンにするまで選べない。スイッチは私が後でオンにするので、あなたは設定を書くところまで進める。
   - **毎回確認させる操作**（`permissions.ask`）：
     - `Bash(rm *)`（ファイルの削除）
     - `Bash(git push *)`（外への送信）
     - `Edit(~/.claude/settings.json)`（この設定そのものの書き換え）
     - Windows なら `PowerShell(Remove-Item *)`・`PowerShell(git push *)` も
   - **絶対にやらせない操作**（`permissions.deny`）：
     - `Bash(git push *--force*)`・`Bash(git push *-f*)`・`Bash(git reset --hard *)`・`Bash(sudo *)`
     - Windows なら `PowerShell(git push *--force*)`・`PowerShell(git push *-f*)`・`PowerShell(git reset --hard *)` も
     - パスワードや鍵のファイル：`Read(//**/.env)`・`Read(//**/.env.*)`・`Read(~/.ssh/**)`（先頭の `//` で、どのフォルダにある .env も対象になる。`//` が無いと作業フォルダの下だけ。公式ページの表のとおり）
   - 書き方は、必ず公式ドキュメント https://code.claude.com/docs/ja/permissions で確かめてから書く。確かめられなかった項目は入れずに「未確認」として報告する。
4. サンドボックス（コマンドが触れる範囲をOSで制限する機能）は、公式ドキュメント https://code.claude.com/docs/ja/sandboxing によると macOS・Linux・WSL2 だけで使える。
   - Mac なら有効にする。
   - Windows（WSL2 を使っていない）なら設定に入れず、「このパソコンでは使えない」と報告する（入れても効かないのに、守られていると思い込むのを防ぐため）。
5. 書き終わったら、ファイルを読み直して、JSON として正しいか・設定が入っているかを確かめる。
6. 最後に、次を専門用語なしで短く伝える。
   - 何を変えたか（3行以内）
   - 元に戻す方法（コピーがあればそれを戻す。元から無かったなら「このファイルを消せば元どおり」）
   - 私がアプリの画面で自分でやる所（下の「画面でやること」）

## 画面でやること（私が自分でやる。あなたは案内だけ）
1. 設定の「Claude Code」の中にある、権限をバイパスするモードを許可するスイッチをオンにする（公式ヘルプの英語表記は「Allow bypass permissions mode」）。これを入れないと、モードの選択肢に出てきません。
2. Code の画面のモード選択で「権限をバイパス」を選ぶ。
3. 設定の「プライバシー」で、会話をAIの改善に使うスイッチ（画面の表記は「AIモデルの改善に協力する」）をオフにする。オフにすると、会話の保管期間が短くなり、学習に使われません。
4. 夜中など、パソコンを離れている間も動かしたいときは、設定の中の、パソコンをスリープさせない設定をオンにする（公式の英語表記は Settings → This computer → System の「Keep computer awake」）。アプリは開いたまま、ノートパソコンのふたは閉じない。

## 大事な注意（私に必ず伝えること）
- このモードは、聞かずにファイルの削除・コマンドの実行・ネットへの接続までします。公式ドキュメントも「このモードは、Claude Code が損害を引き起こせないコンテナや VM などの隔離された環境でのみ使用してください」と注意しています（2026-10-14 確認）。
- 読んだWebページの中に仕込まれた悪い指示にも、ほぼ無防備です。自分の設定ファイルも書き換えられます（だから上で確認させる操作に入れています）。
- 禁止リストも完全な壁ではありません。別の書き方のコマンドや、プログラム経由の読み書きはすり抜けることがあります。大事なデータはバックアップを取り、パスワードやAPIキーを作業フォルダに置かないでください。
- Windows では、コマンドが届く範囲をOSで制限する壁（サンドボックス）がありません。
- 心配なら、確認を減らしつつ安全チェックが残る「自動」モードが、公式のおすすめです。
