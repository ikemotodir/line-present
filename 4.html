特典 4

【まずこれ作れ②】AI学習を効率化する「Webサイト全画面スクショ」丸投げ開発ノート

こんにちは、池本です。

この特典は、ボクが AI に丸投げして作った道具 PATTI SHOT の開発ノートです。
PATTI SHOT は、Webページを一番下まで丸ごと1枚の画像（PNG）や PDF に保存する、Chrome の拡張機能です。無料で、登録もいりません。

拡張機能＝Chrome にあとから付け足す、小さな追加の道具のことです。

うまくいった話だけでなく、つまずいたこと・まだ直しきれていないことも、そのまま書きます。
自分で作るときに同じ穴に落ちないための“地図”として使ってください。

1. なぜ作ったか

ふつうのスクリーンショットは、いま画面に見えている範囲しか撮れません。長いページを残そうとすると、スクロールしては撮って……を何回もくり返すことになります。

ボクが欲しかったのは、この2つをかなえる道具でした。

  • 長いWebページを、1枚の画像や PDF にまとめて AI に渡したい
  • 調べた結果を、あとで見返せる資料として残したい

ボクの場合、実際に撮りたかったページのひとつが、特許や商標を無料で調べられるサービス J-PlatPat（特許情報プラットフォーム）の検索結果です。百行を超える一覧が縦にずっと続くページで、これを丸ごと残したかったんです。

2. 最初の頼み方

ボクは、こんな順番で AI に頼みました。

  1. チャット用の AI（Claude のチャット画面）に、何を作りたいかを話して、開発の指示書を書いてもらう
  2. その指示書を開発用の AI（Claude Code）に渡して、作るところから試すところまで任せる

Claude Code＝ファイルを書きかえたり、プログラムを動かしたりして、実際の作業まで進めてくれる開発用の AI です。

指示書に入れていたのは、主にこの5つです。

  • 使う人の体験を1手ずつ（ダウンロード → ダブルクリックすると専用のブラウザが開く → 撮りたいページで右下のピンクのボタンを押す → 保存される → 保存フォルダが開く）
  • AI が自分で試す仕組み（本物のページを12件以上えらび、空白・二重・抜けがないかを機械で判定する）
  • 合格の条件（全部合格するまで報告しない。試していないことは“合格”ではなく“未検証”と書く）
  • ボクをテスト係にしない・作業中に質問しない
  • 段階に分けて、段階ごとに止まって報告する

ただ、この指示書には大事なことが2つ抜けていました。これが後で大きなつまずきになります（3章・4章）。

  • “いま見ているページを、いつもの Chrome のまま撮りたい”という使い方（指示書には、むしろ“専用のブラウザが開く”と書いていました）
  • “ボクは Chrome を使っていて、画面はこういう設定”という、ボクの環境

3. 開発の流れ：アプリから拡張機能へ作り直した理由

実は PATTI SHOT は、形を何度も変えています。

  • 初期のころ：Chrome の拡張機能の形で試していた時期がありました。そのあと指示書で“拡張機能はやめる。ストアの審査もしない。Windows 用のアプリにして、ボクの道具のページから配る”と決めて、いったんやめました
  • 2026年7月22日〜25日：Windows 用のアプリ（ダブルクリックで動くファイル）として作り直し。自動で新しい版に入れ替わる仕組みまで完成。……でも、実際に触ったら“使えない”
  • 7月26日〜29日：もう一度、Chrome の拡張機能として作り直し。7月29日に公開。いまはこちらが主役です

アプリ版で起きたこと（7月25日）

完成の報告を受けて触ってみると、こうでした。

  • 起動すると、別のブラウザが開く
  • いま開いているページでは使えない
  • 開いたブラウザに、ログインできない
  • 画面を半分の大きさにすると、ボタンが見えなくなる

スクショを撮る道具なのに、撮りたいページで使えない。
何度も同じお願いをくり返して、正直、ボクもへとへとでした。

なぜアプリでは無理だったのか

アプリ版は、PATTI SHOT 専用の Chrome を別に立ち上げて、その中で撮る仕組みでした。

いつもの Chrome を外から操作できれば解決するのですが、Chrome は2025年3月に安全のための変更を発表しています。ログイン情報を盗む手口に悪用されるのを防ぐため、外のプログラムがいつもの Chrome を操作できないようにした、というものです（Chrome 136 から）。

AI に3つの別の方法を試させましたが、どれも Chrome かセキュリティソフトに止められました。

拡張機能ならできる理由

拡張機能は、Chrome の中で動く部品です。だから、いつもの Chrome のまま、いま見ているページを、ログインしたまま撮れます。

作り直しといっても、ゼロからではありません。アプリ版で試して確かめた撮影の中身（ページの長さを測る部分など）は、そのまま拡張機能に移しました。

教訓：何ができるかだけでなく、いつ・どこで・どう使うかを最初に書く。

4. つまずいたところと教訓

① 長いページで、同じ行が二度出る

長いページは、少しずつスクロールしながら何枚も撮って、つなぎ合わせて1枚にします。そのつなぎ目で、一覧の番号が二度出てしまう不具合が出ました。

7月25日から29日までの5日間で、AI から“直しました”と報告を受けて試すたびに再発、を6回くり返しました。直すと別の新しい不具合が出ることもありました。

わかった原因のひとつ：つなぎ目の位置を“ページが教えてくれるスクロールの位置”で決めていたのですが、ボクのパソコンでは、その位置と実際に撮れた絵がずれていました。AI の試験用のパソコンでは、このずれが出ませんでした。

教訓：AI の“直しました”“確認しました”をそのまま信じない。AI 自身に答え合わせをさせる方法を先に決める。

ボクの場合は、1行ずつ番号を入れた練習用のページを撮らせて、“番号が1回ずつ・順番どおり・抜けなく並んでいるか”を機械で数えさせました。

② 途中で切れる

とても長い一覧（縦の長さが 48,330 ピクセル。ピクセル＝画面の点の数）を撮ったら、一覧の20件目あたりまでで保存されていました。

原因：下までスクロールしてから、少し遅れて続きが表示されるタイプのページでした。続きが届く前に“ここが一番下だ”と思い込んで撮っていたんです。AI のパソコンは速くて間に合うので、同じことが起きませんでした。

教訓：ページが言う長さを信じない。撮り終わったあとに、もう一度長さを測る。

途中までしか撮れなかったときは、黙って保存せず、はっきり知らせる。いちばん危ないのは“ちゃんと撮れたように見える、不完全な画像”です。

③ “自分のパソコンでは大丈夫”を信じない

何日もやりとりしたあとで、AI がずっと Edge（別のブラウザ）で試していたことに気づきました。ボクが使っているのは Chrome です（Chrome は、AI が自動で試すときには拡張機能を読み込ませてくれない、という理由はありました）。これに気づくまで、1週間かかっています。

さらに、画面の表示の拡大率の設定も、AI の試験環境は125%、ボクは100%。画面の広さも違いました。この差でだけ出る不具合があったんです。

教訓：最初に“Chrome を使う”“画面の拡大率は100%”など、自分の環境を伝える。そして AI にも同じ条件で試させる。

④ 空白がないことは、合格の証拠にならない

ボクの環境で試したところ、Chrome には、とても長いページを1回で撮ると、1万6千ピクセルあたりを超えたところで、空白ではなく、まちがった中身の画像になるという落とし穴がありました。見た目はそれっぽいので、“空白がないか”の確認では見つかりません。

教訓：合格は“中身が正しいか”で決める（①の番号の答え合わせのように）。

⑤ 配る道具は、セキュリティソフトに止められることがある

アプリ版は、ボクのパソコンのウイルス対策ソフトに起動そのものを止められ、確認すらできない時期がありました。署名（作った人を証明するしるし）のない個人開発のアプリでは、警告が出ることがあります。拡張機能版では、この警告は出ません。

教訓：人に配る物を作るなら、最初からこの問題を計算に入れておく。

ボクの決断

5日間、いちばん性能の高い AI の設定で頼んでも、①の“二度出る”は、ボクのパソコンでは直りきりませんでした。

ボクは7月29日、修正を打ち切って、今の版を公開すると決めました。使える状態で出して、弱点は正直に書く。それが次の5章です。

5. いまの状態（正直に）

2026年9月26日時点です。

  • 主役は Chrome 拡張機能版 v5.5.1（2026年7月29日公開）。Windows 用のアプリ版（v4.2.3）も同じページから入手できます（アプリ版は3章のとおり、専用のブラウザを開いて、その中で撮る仕組みです）
  • とても長いページでは、環境によって、つなぎ目が乱れる（同じ行が二度出る）ことがあります。公開した7月29日の時点で、ボクのパソコンでも起きていました。そのあと、撮影の部分は直していません
    • そのかわり、撮ったあとに PATTI SHOT 自身が画像で答え合わせをして、確かめきれなかったときは、保存するときの通知と、画像と一緒に保存される記録ファイル（_log.txt）で知らせます
  • 拡張機能版は、新しい版が出ても自動では入れ替わりません。ツールバーの PATTI SHOT のアイコンを押した画面に、新しい版が出ていることのお知らせが出るので、手で入れ替えます（Chrome の仕様です。自動で入れ替わる Chrome ウェブストア版は、公式ページで「準備中」としています）
  • 公式ページでは Windows / Mac / Linux（Chrome が動く環境）で使えるとしています。ボクがふだん使っているのは Windows です
  • 撮った画像や PDF は、パソコンの中だけに保存されます。どこかに送られることはありません

6. 入手先と使い方

入手先（無料・登録不要）
https://ikemotodir.github.io/patti-shot/

入れ方（最初の1回だけ）

  1. 公式ページの拡張機能版のボタンから zip ファイルを保存して、展開する
  2. 展開したフォルダを、あとで動かさない場所に置く（例：ドキュメントの中）
  3. Chrome のアドレス欄に chrome://extensions と入れて開き、右上の「デベロッパー モード」をオンにする
  4. 「パッケージ化されていない拡張機能を読み込む」を押して、2 のフォルダを選ぶ

使い方

  • 撮りたいページを開くと、右下にピンクの「PATTI SHOT」ボタンが出ます。押すだけです（キーボードの Ctrl＋Shift＋S でも撮れます）
  • 保存先は、ダウンロード フォルダの中の PATTI SHOT フォルダ。PNG・PDF・記録ファイルが入ります
  • 保存形式（PNG / PDF / 両方）と画質（1倍・2倍・3倍）は、ツールバーの PATTI SHOT のアイコンから変えられます
  • PDF は、長すぎると規格の上限に合わせて、自動で何ページかに分かれます（文字の行が切れない位置で分けます）
  • 商用で使ってもかまいません。ただし、撮ったページの内容の権利はそれぞれのサイトにあります。社内の記録や資料など、決まりの範囲で使ってください

AI に読ませるときのコツ

  • 撮った PNG や PDF を AI のチャット画面に添付して、“この内容を要約して”のように頼みます
  • ただし、長すぎる画像は、そのままだと文字が読めないことがあります。Claude の公式説明では、1枚の画像は縦横8000ピクセルまでで、大きすぎる画像は縮小されて文字が読みにくくなることがある、とされています
  • なので、渡したら最初に“読み取れた内容を、そのまま書き出して”と頼んで、ちゃんと読めているか確かめてから使ってください。読めていなければ、ページの文字をコピーして貼る方法に切り替えましょう

7. 自分で作るなら：丸投げの指示文（コピペ用）

ボクがつまずいたことを、全部最初から入れた指示文です。
開発用の AI（Claude Code など）に、そのまま貼って使えます。〇〇 のところだけ、自分の状況に書きかえてください。

  • Claude Code を使うには、Claude の有料プランなどが必要です（公式の概要ページに記載）
  • この指示文で作っても、同じところでつまずく可能性はあります。ボクの版でも、とても長いページのつなぎ目は直しきれていません
  • 作るより先に、まずボクの PATTI SHOT を使ってみる、でも十分です
Chrome で使う「Webページを一番下まで丸ごと1枚に保存する」拡張機能を作ってください。
私はプログラムの知識がありません。作るところから試すところまで、あなたに任せます。

【私の環境（必ずこの条件で試すこと）】
・ブラウザ：Google Chrome（別のブラウザで試した場合は、報告にそう書くこと）
・パソコン：〇〇（例：Windows 11）
・画面の拡大率：〇〇%　／　画面の広さ：〇〇
　※分からなければ、作業の前に調べ方を1手ずつ教えてください（ここだけは質問してOK）

【使い方（こうなっていれば完成）】
1. いつもの Chrome で、いま見ているページのまま使える（別のウィンドウを開かない・ログインし直さない）
2. 画面右下のボタンを1回押すと、ページの一番下まで丸ごと1枚の PNG と PDF になる
3. ダウンロードフォルダの中の専用フォルダに保存される
4. 撮った画像を外部に送信しない
5. パソコンに詳しくない人でも分かる、1手ずつの「入れ方の説明書」をつける

【合格の条件（1つでも満たさなければ「完成」と言わない）】
・長いページでも、同じ行が二度出ない／行が抜けない／途中で切れない
・見た目や「空白がないか」では判定しない。次の方法で機械的に確かめる
　- 1行ずつ番号を入れた練習用ページ（数百行。似た行がずらっと並ぶ表も入れる）を撮り、
　　画像の中の番号が「1回ずつ・順番どおり・抜けなし」かを数える
　- 下までスクロールしてから、遅れて続きが表示されるページも用意して試す
・撮り終わったら、もう一度ページの長さを測り直す。
　途中までしか撮れなかったときは、黙って保存せず、画面ではっきり知らせる
・実在の長いページでも試す（私がよく撮るページ：〇〇）

【進め方】
・作業中に私に質問しない。迷ったら良いと思う方を選び、理由を最後に1行で書く
・私をテスト係にしない。自分で試せることは全部自分で試す
・試していないことを「動きます」「直しました」と言わない。「未確認」と書く
・報告は3つだけ：
　①合格の条件ごとの結果（合格／不合格／未確認）
　②私がやる作業（1クリックずつ。無ければ「なし」）
　③分かっている弱点

報告に“未確認”が残っていたら、自分で試す前に“未確認をなくしてから、もう一度報告して”と返すのがおすすめです。
