# 動画も資料も「元の言葉のまま」AIに覚えさせる ― Claude Code への丸投げ指示書

## あなた（Claude Code）へ
私はプログラムが分かりません。私が持っている講座の動画・スライド・PDF・資料を、**要約せず、元の言葉のまま**覚えてほしいです。要約だけで覚えると、すぐ忘れて中身も浅くなるからです。
このファイルの手順どおりに「覚えさせる道具」を私のパソコンに用意し、私が「○○を学習して」と頼んだら、毎回この深さでやってください。
- 使うのは、無料で公開されている部品と、OSに最初から入っている機能だけです。処理はパソコンの中で行います。
- 途中で私に質問しないでください。迷ったら良いと思う方を選び、最後に理由を1行で書いてください。
- 管理者のパスワードが要る方法は使わないでください。
- 覚えるのは、私が見る権利を持っている資料だけです。覚えた中身を他の人に配ったり公開したりはしません。

## 1. 道具を用意する（最初の1回だけ）
- Windows か Mac かを調べる。Python は **uv** で用意する。uv が無ければ公式の方法で入れる（Windows は PowerShell で `irm https://astral.sh/uv/install.ps1 | iex`、Mac は `curl -LsSf https://astral.sh/uv/install.sh | sh`）。作業フォルダの中に専用の環境を作る（`uv venv --python 3.12`）。部品はそこに入れ、パソコン全体を汚さない。
  - 通信で `UnknownIssuer` や `CERTIFICATE_VERIFY_FAILED` が出たら、セキュリティソフトが通信を検査している。uv は環境変数 `UV_SYSTEM_CERTS=1` を付けて再実行し、Python からの通信は部品 `truststore` を入れて最初に `truststore.inject_into_ssl()` を呼ぶ。
  - 作った道具は作業フォルダの `tools/` に置き、スキルの名前は `gakushu-kit` にする（毎回作り直さないため）。
- 入れる部品と役目：
  - **faster-whisper**（動画・音声を文字にする。Whisper を速くした無料の部品。動画の読み込みは一緒に入る PyAV を使うので、ffmpeg はパソコンに入れなくてよい。**ただし PyAV は `av<17` を指定して入れる**。2026年10月時点、新しい PyAV 19 だと faster-whisper が `metadata_errors` のエラーで止まる）。モデルは `large-v3-turbo`（約1.6GB。初回だけダウンロードに数分）。GPU が無いと、文字起こしには動画の長さとほぼ同じ時間がかかる
  - **PyMuPDF**（PDFの文字を取り出す）／**openpyxl**（Excel・スプレッドシート）／**requests・BeautifulSoup**（ウェブページ）／**Pillow**（画像を開く）
  - 画像の文字を読む：Windows は OS標準の文字認識を **winocr** で、Mac は OS標準の Vision を **ocrmac** で使う。日本語が読めない設定のときは、そう報告する。Windows の文字認識は日本語の字の間に空白が入るので詰める。濁点・半濁点が落ちることがあるので、数字や固有名詞は手順7で原文と照らす
- NVIDIA の GPU があれば文字起こしに使う。ただし別のプロセスで数秒の試しが成功したときだけ。だめなら CPU（int8）でよい。

## 2. 学習を頼まれたら、毎回この順でやる
1. **入口から最後の資料までたどる。** 教えてもらったページ → 各項目 → その先のスライド・PDF・ドキュメント → フォルダの中 → スプレッドシートの中のリンクまで、全部取る。私に1つずつURLを開かせない。ログインが要るページは、Chrome 拡張「Claude in Chrome」がつながっていればそれで開く（私の画面の前には出さない）。無理なら、どのページが取れなかったかを最後にまとめて伝える
2. **元の言葉を丸ごと残す。** フォルダ `学習/<講師や講座の名前>/原文/` に、1資料1ファイルで保存する
   - 文章・スライド・PDF・シート → 文字をそのまま
   - **動画 → 音声を文字にする**（[00:01:23] の時刻つき）。**画面に出るスライドや字幕も、数秒ごとに静止画を切り出して文字を読み、同じ文字が続く所は1つにまとめる**
   - 動画がURL（YouTube・Vimeo など）のときは、部品 **yt-dlp** で落としてから文字にする。会員制サイトの動画は、ブラウザで開いた状態で動画ファイルのURLを探す。落とせなければ「取れなかった資料」に書く
   - 画像・スキャンした資料 → 文字認識で読む。図の中にしか無い内容は「文字になっていない」と書いておく
3. **要約しない。** 教え・手順・数字・テンプレ・例は全部並べる。手順は元の順番と数のまま。手分けするときも、担当に字数の上限を指示しない。中身を読まずに、検索結果の断片だけで書かない
4. **ナレッジにまとめる。** `学習/<名前>/ナレッジ.md` に、テーマごとの章で整理する。各段落の最後に、どの資料のどこか（資料名・ページ・動画の時刻）を書く。前に作ったナレッジは1文字も書き換えず、新しい分は後ろに足す
5. **呼び出せるようにする。** Claude Code では「スキル」にする（`~/.claude/skills/<名前>/SKILL.md` に、何の相談で使うか・ナレッジと原文の場所・答え方を書く）。講師が何人かいるときは人ごとにスキルを作り、名前を出さない相談では**全員の話を突き合わせてベストな答えを1つ**出す。チャットの Claude で使うときは、ナレッジ.md をプロジェクトのナレッジに入れる
6. **答えるときは元の言葉から引く。** 言い回し・数字・手順は、ナレッジではなく原文フォルダを検索して、元のとおりに出す。どの資料のどこかを添える
7. **自分で照らし合わせる。** ナレッジに書いた数字・手順の数・誰の発言かを、原文と照らす。受講生の実績を講師本人の数字のように書いていないかも見る。違いが0になるまで直す
8. **途中で止まっても続きから。** 進み具合を `学習/<名前>/進み具合.md` に残す

## 3. 最初に1回だけ試してから渡す
- OSの読み上げ機能で短い日本語の音声を作り、文字にできることを確かめる
- 文字の入った画像を1枚作り、文字認識で読めることを確かめる
- 試していないことを「できました」と言わない

## 4. 最後に私へ伝えること（専門用語なしで短く）
1. 学習を頼むときの言い方の例（1行）
2. 覚えた中身が保存される場所
3. 取れなかった資料があれば、その名前

Claude Code（デスクトップアプリの「Code」）で新しいフォルダを開き、ファイルの中身を貼って送るだけ。準備をして、学習の頼み方を教えてくれます。Windows・Mac どちらでも作れるように書いてあります。

細かい解説（5つの裏技）

  • 裏技1 要約させない：手順・数字・例まで、元の順番のまま全部残します。
  • 裏技2 リンクの先までたどる：奥のPDFやスライドまで、AIが自分で取りにいきます。
  • 裏技3 動画は声も画面も文字に：映ったスライドや字幕まで読み取ります。
  • 裏技4 講師ごとに分けて覚える：名前なしで聞けば、全員の話を合わせて1つの答えを出します。
  • 裏技5 答えは原文から引かせる：どの資料のどこかを添えて答えます。

動画を文字にするだけのアプリが欲しい人は、特典5もどうぞ。うまくいかないときは、画面の写真と「何をしたら・どうなった」をClaude Codeに送ってください。

覚えさせるのは、見る権利のある資料だけに。中身を人に配らないでください。

※パソコンやOSによっては動かないことがあります。修正のご依頼はお受けしていません。Macでは試していません。
