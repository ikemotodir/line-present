自動で動き出すClaude設定ガイド

Claude Code は、ふだん作業のたびに「やっていい？」と聞いてきます。これを止めて、任せたら最後まで自動で動くようにする設定です。リスクと守り方もセットで。

使い方

Claude Code（デスクトップアプリの「Code」。入れ方は Lv.2）でフォルダを1つ選び、ファイルの中身を貼って送るだけ。書き込みの許可を聞かれたら「はい」。終わったら、下の②を自分で切り替えてください。

① 丸投げで入る設定（Claude Code が自分でやる）

  • 許可を聞かずに進むモード（権限をバイパス）で始まるようにする
  • そのかわり、削除と外への送信は毎回確認。履歴の上書き・管理者権限・パスワードの読み取りは禁止

② 自分で切り替える所（アプリの画面）

  • 設定の「Claude Code」：権限をバイパスするモードを許可するスイッチをオン（公式の英語表記は「Allow bypass permissions mode」）。これが無いと選べません
  • Code のモード：「自動」→「権限をバイパス」
  • 設定 →「プライバシー」：「Help improve our AI models」をオフ
  • 夜中も動かすなら：設定の中の、スリープさせない設定をオン（公式の英語表記は Settings → This computer → System の「Keep computer awake」）

リスクと守り方

  • 「権限をバイパス」は、聞かずに削除・実行・ネット接続までします。公式も、壊れても困らない切り離した環境だけで使うよう注意しています（2026-10-14確認）
  • だから ①作業用のフォルダを分ける ②大事なデータはバックアップ ③パスワードやAPIキーをフォルダに置かない ④公開・送信・お金は、Lv.5 のルール3で必ず確認させる
  • 禁止リストも完全な壁ではありません。自分で責任を取れない人は、安全チェックが残る「自動」モードのまま使ってください。 その時は、丸投げファイルの最後に、下の枠の文を足して送ってください。
権限をバイパスのモードにはしないでください。それ以外の守りの設定だけを入れてください。
