特典 2

【まずこれやれ②】自動で動き出すClaudeの設定ガイド

ボクが寝ているあいだも、子どもと遊んでいるあいだも、Claude は仕事を進めてくれています。
この特典では、その「自動で動く」仕組みを、いちばんかんたんな方法から紹介します。

この特典で分かること

  • 自動で動くと、何がラクになるのか（ボクの実例）
  • やり方3つと、それぞれに必要なもの
  • Claude に貼るだけで設定が終わる「おまかせ指示文」
  • 事故を起こさないための安全の決まり

1. 「自動で動く」と、何がうれしいの？

ボクの場合①　寝ているあいだに開発が進む「夜勤」

Windows の予約機能（タスクスケジューラ）を使って、毎晩2時にパソコンを起こし、Claude に開発の続きをやってもらう仕組みを作りました。

朝起きると、「ゆうべ何をしたか」と「ボクに決めてほしいこと」をまとめた朝刊ができている、という仕組みです（2026年7月に作りました）。
ボクがまだOKを出していない作業には、夜勤は手を出さない決まりにしています。

ボクの場合②　返事の前に、機械が自動で点検する

Claude が返事を終える直前に、点検が2つ自動で走るようにしています。

  • 作った物があるのに「どこで見られるか」が書いていなければ、返事を止める
  • 小さなAIが報告の最後の「確認してほしいこと」だけを読み、何も知らない人が読んで分からなければ、止めて書き直させる

「ルールに書いておいたのに、また同じミス」が続いたので、文章でお願いするのをやめて、機械に止めてもらうことにしました。

うれしいことをまとめると

  • 自分が手を離しているあいだに、仕事が前に進む
  • 毎回同じお願いを打ち込まなくていい
  • 「やり忘れ」「書き忘れ」を、AIの気分ではなく仕組みで防げる

ただし、完全におまかせではありません。朝に結果を見て、決めるのは自分です。

2. やり方は3つ（かんたんな順）

まず前提

  • ここで使うのは Claude Code（クロード・コード）です。チャットで話すだけのAIとちがい、パソコンの中のファイルを実際に作ったり直したりできる「開発用の Claude」です
  • Claude Code は有料プラン（Pro・Max・Team・Enterprise）で使えます。無料プランには入っていません（Pro は月払いで月20ドル・税別。2026年9月26日時点の公式料金ページ）
  • いちばん手軽なのは、Claude のデスクトップアプリ（Windows・Mac）の Code タブです

※このあと出てくる太字のボタン名は、公式ヘルプ（英語版）の表記です。日本語表示の画面では言い方がちがうことがあります。

① デスクトップアプリのスケジュール実行　★いちばんかんたん

決めた時間になると、Claude が新しい作業を自動で始めます。自分のパソコンの中のファイルをそのまま使えます。

  • 使えるプラン：Pro 以上
  • 必要なもの：Claude デスクトップアプリ（古い版だと使えないので、最新にしておく）
  • 作り方：Code タブの中で「毎朝9時に〇〇して」と頼むだけで作れます。画面から作るなら、サイドバーの Routines（見当たらなければ、サイドバーの More の中）→ New routine → Local
  • 時間の選び方：手動のみ／1時間ごと／毎日／平日だけ／毎週。「15分ごと」なども、頼めば設定してくれます
  • 注意：アプリが開いていて、パソコンが起きているときだけ動きます

② フック　「〇〇したら、必ず△△する」を守らせる

決まったタイミングで、決まった処理を必ず動かす仕組みです。AIが「やるかどうか」を選ぶのではなく、毎回かならず動きます。ボクの「返事の前の自動点検」はこれです。

  • 使えるプラン：Claude Code が使えるプランならOK
  • 必要なもの：設定ファイルへの書き込み。自分で書かなくても、Claude に頼めば入れてくれます。直すのも外すのも、Claude に頼めます（黒い画面で使う版の Claude Code なら、/hooks と打つと、入っているフックの一覧も見られます）
  • 動くタイミングの例：返事を終える直前／ファイルを書き換えたあと／こちらの許可を待っているとき（通知を出す）など
  • 小さなAIに点検させる型もあります。公式の例は「頼まれたことが全部終わったか点検して、終わっていなければ続きをやらせる」というものです
  • 注意：「返事を終える直前」のフックは、作業が完了したときだけでなく、返事をするたびに動きます

③ クラウドのルーティン（Routines）　パソコンを閉じていても動く

Anthropic（Claude を作っている会社）のコンピューターの上で、決めた時間に動きます。

  • 使えるプラン：Pro・Max・Team・Enterprise。いまはお試し提供（research preview）の段階で、中身や上限が変わることがあります
  • 必要なもの：GitHub（ネット上のファイル置き場）。毎回そこから作業用のコピーを取って動くので、自分のパソコンのファイルは見られません
  • 作る場所：claude.ai/code/routines、またはデスクトップアプリの New routine → Cloud
  • 注意：最短でも1時間おき。1日に動かせる回数にも上限があります（アカウントごと）。そして許可を聞かずに動きます（くわしくは4章）

3つのちがい

①スケジュール実行②フック③ルーティン
動くきっかけ決めた時間決めたできごと決めた時間など
パソコンの電源必要必要いらない
自分のファイル使える使える使えない
かんたんさ★★★★★★

おまけ：ほかにもある方法

  • /loop：Claude Code を開いているあいだだけ、同じお願いをくり返します（例：/loop 30m 〇〇を確認して で30分ごと）。閉じると止まり、7日で自動的に終わります
  • ボクの「夜勤」方式（上級者向け）：Windows の予約機能から、画面を開かずに Claude を1回だけ動かす呼び出し方（claude -p）を使います。スリープ中のパソコンを起こして動かせるのが強みです。ただ、デスクトップアプリとは別に、黒い画面で使う版の Claude Code を入れる必要があり、許可の設定や失敗の見張りも自分で組むので、①で物足りなくなってからで十分です

3. はじめの一歩：これを貼るだけ

手順

  1. Claude デスクトップアプリを開いて、Code タブへ
  2. 作業するフォルダを選ぶ（最初は、大事なファイルが入っていない練習用の新しいフォルダがおすすめ）
  3. 下の文をそのまま貼って送る

指示文A：毎朝のまとめを自動で作る（①スケジュール実行）

Claude デスクトップアプリで、決まった時間に自動で動く「スケジュール実行のタスク」を1つ作ってください。

■ 動かす時間：毎日 朝6時
■ 作業するフォルダ：いま開いているこのフォルダ

■ 準備（いま1回だけ）：
・このフォルダに「やることメモ.md」が無ければ、見本を1つ作っておく

■ 毎回やること：
・このフォルダの「やることメモ.md」を読んで、今日やることを3つにしぼり、「けさのまとめ.md」に書く
・書いてよいのは「けさのまとめ.md」だけ。ほかのファイルは変えない

■ 守ってほしいこと
・ファイルを消さない
・メール・SNS・買い物・支払い・申し込みなど、外に何かを送ることは一切しない
・パソコンが寝ていて時間がずれたら、その日の分だけやる（前の日の分はやらない）
・分からないことがあっても勝手に決めず、まとめの一番上に「確認したいこと」として書く

作ったら、
①何が・いつ動くか　②一時停止のしかた　③消し方
を、専門用語なしで教えてください。
そのあと、1回目を試しに動かすときに、どの許可を出せばいいかも教えてください。

送ったあとは、サイドバーの Routines から Claude が作ったタスクを開き、Run now（今すぐ実行）を押して1回動かします。
このとき許可を聞かれたら、内容を読んでから、次からも許可する選択肢を選びます。そうしておくと、次からは同じ操作を聞かずに進みます。
（ここで許可を出しておかないと、夜中に許可待ちで止まったまま朝をむかえます）
ただし、ファイルを消す操作や、外に何かを送る操作の許可を聞かれたときは、許可しないでください。指示文で頼んでいない動きです。

指示文B：返事の前に自動で点検させる（②フック）

Claude Code が返事を終える前に、自動で点検する仕組み（フック）を入れてください。

■ 点検すること
頼んだことが全部終わっているか。終わっていなければ、終わらせてから返事をする。

■ 条件
・まずは、いま開いているこのフォルダの作業にだけ効くようにする（慣れたら全体に広げる）
・いまの設定ファイルは、変える前にコピーを取っておく
・点検が何度も続いて、いつまでも終われなくならないようにする
・入れたあと、ちゃんと動くか1回試して、結果と「元に戻す方法」を専門用語なしで教えてください

慣れてきたら「点検すること」を、自分がよくされるミスに書きかえてください。
たとえば「最後に、ボクが次にやることが1行で書いてあるか」など。

4. 安全の決まり（これだけは守って）

① 勝手に消させない

  • 指示文には、かならず「ファイルを消さない」を入れる
  • 最初は練習用のフォルダで。大事なフォルダを使うときは、先にコピーを取っておく
  • 何でも聞かずにやってしまうモードは使わない。壊れても困らない、切りはなされた環境（専用の仮想パソコンなど）でだけ使うように、と公式ヘルプにも書かれています
  • 「これはダメ」という禁止リストも作れます。ただし公式も完全な壁ではないと書いているので、指示文での約束とセットで使います

② お金と送信には、さわらせない

  • 買い物・支払い・メール送信・SNS投稿・申し込みは、自動の仕事に入れない
  • ③ルーティンは、つないでいる外部サービス（Slack や Google ドライブなど）が最初は全部入りで、しかも許可を聞かずに書き込めます。いらないものは作るときに外します。そこでの操作は、あなた本人の名前で行われます
  • ボクの場合：決めてほしいことは朝刊に書かせて、ボクがOKしたものだけ次の晩にやる決まりにしています

③ 使用量（プランの利用枠）

  • Pro・Max プランでは、Claude Code とチャットは同じ利用枠を分け合います。自動で動いた分も、その枠から使われます
  • 最初は「1日1回・1つだけ」から。1時間ごとにするのは、様子を見てから
  • 残りは claude.ai/settings/usage で確認できます（黒い画面で使う版の Claude Code なら /status でも見られます）
  • 「小さなAIに点検させる」フックは、返事のたびにAIを呼びます。使用量の減り方を見ながら使ってください

④ パソコンの電源とスリープ

  • ①スケジュール実行は、パソコンが寝ていたり、アプリを閉じていたりすると、その回は飛ばされます。次にパソコンが起きたとき（またはアプリを開いたとき）に、飛ばされた回のうちいちばん新しい1回分だけ動きます。さかのぼるのは直近7日までで、それより前の回はやり直しません
  • アプリの設定の Desktop app → General にある Keep computer awake をオンにすると、放っておいて勝手に寝るのを防げます。ただし、ノートパソコンのふたを閉じると寝ます
  • 「朝9時のつもりが、夜に動いた」も起こります。指示文に「時間がずれたら、今日の分だけやる」と書いておくと安心です（指示文Aに入れてあります）
  • パソコンを閉じていても動かしたいなら、③ルーティンを使います
  • ボクの夜勤は、Windows の予約機能にある、スリープ中のパソコンを起こす設定を使っています。ノートパソコンでやるなら、電源につないでおくのがおすすめです

⑤ 朝に、かならず結果を見る

  • ①は動くと通知が来て、サイドバーの Scheduled に作業のあとが残ります
  • ③の一覧で緑色になっていても、「エラーなく終わった」という意味で、「頼んだことが成功した」という意味ではありません。中身を開いて確かめます
  • 止めたいときは、タスクの画面で一時停止できます。①を消すときは、タスクの画面の Delete ボタンを使います（一時停止や変更は Claude に頼めますが、消すのはボタンで、と公式ヘルプにあります）

さいごに

自動化は、「任せっぱなし」にするためではなく、自分の時間を取り戻すためのものです。
まずは指示文Aを1つだけ動かして、1週間、毎朝のまとめを読んでみてください。慣れてきたら、少しずつ任せる仕事を増やしていきましょう。

設定でつまずいたら、特典5の無料個別相談で一緒にやりましょう。
